# opencode-command-hotkeys

[English](README.md)

Настраиваемые горячие клавиши для команд OpenCode и переключение Goal между паузой и продолжением.

- Назначение серверных команд на выбранные клавиши.
- Пауза и продолжение текущей Goal одной клавишей.
- Запуск действий без замены или отправки черновика.

## Совместимость

TUI OpenCode 2.2.5. Для сборки из исходников нужны Node.js >=22.18.0 и npm.

## Установка

Установите пакет в отдельный каталог:

```sh
mkdir -p "$HOME/.local/share/opencode-command-hotkeys-install"
cd "$HOME/.local/share/opencode-command-hotkeys-install"
npm install --ignore-scripts opencode-command-hotkeys@0.1.1
```

В `cli.json` укажите абсолютный путь к установленному каталогу пакета, заканчивающийся на `node_modules/opencode-command-hotkeys`.

Для локальной копии исходников выполните команды ниже и используйте путь к каталогу проекта:

```sh
npm ci --ignore-scripts
npm run build
```

## Конфигурация

Добавьте запись в существующий список `plugins`. Замените путь из примера на каталог пакета, а не на JavaScript-файл.

```json
{
  "plugins": [
    {
      "package": "/absolute/path/opencode-command-hotkeys",
      "options": {
        "bindings": [
          {
            "id": "review-changes",
            "key": "ctrl+alt+r",
            "title": "Проверить изменения относительно main",
            "command": "review",
            "text": "main"
          },
          {
            "id": "goal-toggle",
            "key": "f4",
            "title": "Приостановить / продолжить цель",
            "action": "goal-toggle"
          }
        ]
      }
    }
  ]
}
```

Привязок по умолчанию нет. В примере Ctrl+Alt+R вызывает встроенную команду `review` для сравнения текущей ветки с `main`, переданной в `text`; замените `main` на нужную базовую ветку. F4 приостанавливает или возобновляет текущую Goal. Действия также доступны в палитре команд.

## Поведение

Действия относятся к текущей сессии. При открытом диалоге горячие клавиши не работают; черновик не отправляется и не заменяется.

`goal-toggle` приостанавливает активную Goal и возобновляет приостановленную. Если цели нет или она завершена, ничего не происходит. Новая Goal не создаётся.

Пауза Goal приостанавливает её автопродолжение. Это не Escape: текущая генерация ответа не прерывается.

Повторный вызов той же привязки в той же сессии игнорируется до завершения запроса. Остальные привязки и сессии работают независимо.
