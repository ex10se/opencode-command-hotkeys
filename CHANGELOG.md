# История изменений

## 0.1.1

### Изменено

- Первым примером привязки показана команда `review` с аргументом `main` через поля `command` и `text`.
- Переключение Goal вынесено во второй пример; пояснения синхронизированы в README на двух языках и справочнике конфигурации.

## 0.1.0

### Добавлено

- Настраиваемые горячие клавиши серверных команд OpenCode через `options.bindings`.
- Действие `goal-toggle` для паузы и продолжения текущей Goal.
- Отображение действий в палитре команд.
- Проверка конфигурации, алиасов клавиш и пересечений альтернатив.
- Защита от повторного вызова одной привязки в одной сессии.
- Блокировка клавиатурных действий при открытых диалогах.
- Сохранение черновика при вызове команд.
- Проверки упаковки, зависимостей и безопасности в CI
