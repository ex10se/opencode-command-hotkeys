# Безопасность

## Модель доверия

Конфигурация плагина определяет команды и аргументы, которые выполняются в текущей сессии. Проверяйте `command`, `text` и `action` перед добавлением привязки. Не храните секреты в названиях действий или аргументах: они могут попасть в конфигурацию и историю сессии.

Плагин не обходит разрешения OpenCode. Клавиатурные действия не запускаются поверх диалогов, а выбор из палитры требует закрытия её диалога. Ошибки показываются без аргументов и текста исходного исключения.

Пауза Goal не является аварийной остановкой: она приостанавливает автопродолжение, но не прерывает текущую генерацию. Переключение читает состояние и отправляет команду отдельными запросами; другой клиент может заменить Goal между ними.

Блокировка повторного вызова действует только для одной привязки и сессии внутри экземпляра плагина. Она не синхронизирует разные клиенты или поколения перезагрузки.

## Зависимости

Runtime npm-зависимостей нет. SDK OpenCode используется при разработке.

Dev-граф использует парные overrides `glob: 14.0.3` и `minimatch: 11.0.4`. Обновление только minimatch несовместимо с API старого glob. Для сопровождения сверяйтесь с [advisories glob](https://github.com/isaacs/node-glob/security/advisories) и [advisories minimatch](https://github.com/isaacs/minimatch/security/advisories).

После обновления запускайте `npm run test:dependencies` и `npm audit --audit-level=moderate`. Полный аудит включает dev-граф. Удаляйте overrides после исправления upstream и успешных регрессионных проверок; чистый audit не заменяет анализ безопасности.
